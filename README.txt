KARIBASAVA & VANDANA — DIGITAL WEDDING INVITATION

HOW TO ADD PHOTOS
1. Open the images folder.
2. Copy your photos into it and rename them exactly:
   couple.jpg    -> main couple photo (both together)
   groom.jpg     -> groom photo
   bride.jpg     -> bride photo
   gallery-1.jpg -> gallery photo 1
   gallery-2.jpg -> gallery photo 2
3. Optional: add background.jpg for a custom background image.
4. Use JPG or PNG. If using PNG, either convert to JPG or update the matching file extension in index.html.

HOW TO PREVIEW
- Extract this ZIP.
- Open index.html in a browser. For best results, use a simple local server or upload to GitHub Pages.

FREE HOSTING WITH GITHUB PAGES
1. Sign in at https://github.com/
2. Create a new public repository, e.g. karibasava-vandana-invitation.
3. Upload all files and folders from this project (keep the same folder structure).
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. GitHub will provide a public website link after deployment.

EDITING
- Names, dates, address, phone and map URL are in index.html.
- Design colours and layout are in style.css.
- Countdown target is in script.js.
- No paid libraries or database are required. Google Fonts needs internet access.
- The WhatsApp confirmation button opens a pre-filled message to 9535874134.
- The music folder is intentionally empty. Add only music you have permission to use, then add a player if required.
